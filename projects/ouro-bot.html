Ouro Bot

A compact tracked robot being developed to map an apartment, recognize household clutter, and alert the user when it finds something that needs attention.

Project direction

Ouro Bot combines mobile robotics, computer vision, and mechanical packaging in one household platform. The current concept uses a tracked drivetrain and a tilting sensor head so the robot can move through indoor spaces and inspect its surroundings.

Planned architecture

A 2D LiDAR will support SLAM-based mapping while a Raspberry Pi and Pi Camera run the visual detection pipeline. The enclosure is being modeled alongside the drivetrain, compute, power, and sensing bill of materials to surface interface problems before assembly.

Next build milestone

The image above represents an early mechanical direction rather than a finished robot. The next iteration will finalize subsystem interfaces, assemble the drivetrain, and test mapping and object detection on real household scenes.
